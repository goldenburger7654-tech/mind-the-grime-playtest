# Mind the Grime

A subway janitor story. You are the night janitor on the New York subway: clean the station,
earn its gold star, and the Last Train takes you to the next one.

This repository exists only to hand out **playtest builds**. The game's source lives elsewhere.

## Download

**[Get the latest build](../../releases/latest)** — Windows, 64-bit, nothing to install.

Unzip it, then run `MindTheGrime.exe`. Keep the `.pck` file in the same folder; the game will not
start without it. Windows may say "Windows protected your PC" the first time, because the build is
not signed — click **More info**, then **Run anyway**.

## Controls

| | |
|---|---|
| `WASD` | walk |
| `Shift` | run |
| Mouse | look |
| Hold left mouse | scrub the floor with whatever is in your hands |
| `E` | pick things up, and use anything you are looking at |
| `Esc` | pause menu and options |
| `F8` | change the picture: VHS, CRT, Dreamcast, clean, and so on |

## What you are doing

Clean the station. It is done when the floor is 90% clean with no litter left — that earns a gold
star, and the Last Train will not leave without one. It waits as long as you need.

Cans and bottles go in the recycling machine for cash, everything else in a bin. Your bag only
holds so much. The Supply Closet on the platform sells better gear, and the Training Board beside
it trains skills. There is a subway map on the wall, and the real subway behind it — 25 lines and
443 stations.

There are rats. Nothing tells you what to do about them.

## Feedback

Whatever you noticed is worth hearing, however rough:

1. How long before you understood what you were meant to be doing?
2. Did you find anything by accident that felt good to find?
3. When did you get bored, and what were you doing at the time?
4. Anything that looked wrong, broke, or ran badly — and what sort of machine you are on.

Your save lives in `%APPDATA%\Godot\app_userdata\Mind the Grime`. Delete that folder to start
completely fresh.
